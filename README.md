# CMP Particle Pressure Simulator (R02)

Pad 경도·Bulk Modulus·Head 압력·슬러리 Solid contents 를 입력하면
Pad 돌기 접촉의 탄성/소성 여부, 입자 하나가 받는 하중, 임계압력, 스크래치 가능성을 계산하는 데스크톱 GUI.

- 저장소: HeroHJ0401/CMP_PARTICLE_SIM (로컬 `CMP/particle-build/`). 파일: `cmp_particle_pressure_sim_R02.py`
- 의존성: **파이썬 표준 라이브러리만** (tkinter 포함). numpy/matplotlib 불필요.
- 실행: `python cmp_particle_pressure_sim_R02.py`
- 빌드: GitHub Actions `.github/workflows/build.yml` 하나가 push 시 Windows EXE 와 macOS .app 을 **동시에** 빌드한다. 저장소에서 가장 높은 R번호의 스크립트를 자동으로 찾아 산출물 이름에 버전을 붙인다 (예: `CMP Particle Pressure Simulator R02.exe`, `... R02-macOS.zip`). 새 버전은 파일명의 R번호만 올려서 push 하면 된다.

## R01 → R02 변경 요약

| 항목 | R01 | R02 |
|---|---|---|
| H_pad 산출 | 기본값이 "경도 환산 E" 경로라 화면의 E_tip 과 다른 E 를 사용 (Shore A 20 이면 163 kPa) | **E_tip × (H/E) × f_rate** 로 통일. 직접 입력(글레이징·나노압입)도 가능 |
| 속도·경화 보정 | 없음 | f_rate (기본 5) 를 **E 와 H 에 동시** 적용. 직접 입력 모드에서는 E ≥ H_eff/(H/E) 로 일관성 유지 |
| 입자 매립 | F_emb = H·πR² 고정 | Pad 반력 = Wafer Hertz 반력, δ_p + δ_w = 2R 하중 평형으로 δ_p, δ_w 계산 |
| 스크래치 1차 | 벌크 잔류 압흔만 | **수화층(t_h, H_h) 관통 → 나노스크래치**, 홈 폭 출력 |
| 스크래치 2차 | — | 벌크 잔류 압흔 ≥ δ_th → 깊은 스크래치 (별도 표시) |
| 분포 | 단분산 | 로그정규 CV 로 **상위 99.9 % 입자** 하중·판정 추가 |
| LPC | 없음 | 응집체 지름 d_L 과 LPC [counts/mL] 분리 입력, 실접촉 내 순간 접촉 수 추정 |
| 활성 입자 비율 기본값 | 1.0 | 0.05 |

## 2. 출력

- E_tip, 정적 경도 H_static, **유효 경도 H_eff**, 접촉역학용 E_dyn
- **소성지수 ψ**, 임계압력 P_crit (소성 돌기 하중분담 50 %), 현재 압력의 임계 이상/이하 판정
- 실접촉면적비, 돌기 접촉압력, 입자 수밀도·간격, 활성 입자 수
- Head 압력 분담 하중 F_share, **하중 평형 하중 F_bal**, 입자당 하중 F_p = min, 매립 깊이 δ_p, 상위 99.9 % 입자 하중
- Hertz 접촉압력 p_m, 벌크 변형 모드, 벌크 항복에 필요한 Pad 경도
- **① 나노스크래치**: 관통에 필요한 하중·Pad 국소 압력·홈 폭, 단일 입자 압흔 깊이·폭, 중앙값/99.9 % 입자 판정, 임계 응집체 지름
- **② 깊은 스크래치**: 벌크 잔류 압흔 깊이·폭, 판정, 임계 응집체 지름
- **③ LPC**: 실접촉 내 순간 접촉 수(300 mm 웨이퍼), d_L 이 임계 지름을 넘는지
- 그래프: Head 압력(log) 대비 소성 분담률, 입자당 하중, 수화층 관통 하중 F_need, P_crit, 현재 압력

## 3. 계산 흐름

### 3.1 경도 → 탄성계수 환산

| 척도 | 식 | 출처 |
|---|---|---|
| Shore A | Gent: E[MPa] = 0.0981(56 + 7.62336 S) / (0.137505(254 − 2.54 S)) | Gent, Trans. IRE 34, 46 (1958) |
| Shore D | Ruess: log10 E[MPa] = 0.0235 (S + 50) − 0.6403 | Qi, Joyce, Boyce, Rubber Chem. Technol. 76, 419 (2003) |
| Asker C | 근사 대응표로 Shore A 로 바꾼 뒤 Gent 식 | 듀로미터 비교표 기반 근사치. `ASKER_C_TABLE`/`SHORE_A_TABLE` 교체 가능 |

경도 환산 E 는 Bulk Modulus 를 비워 두었을 때만 쓰이고, 그 외에는 입력 Modulus 와의 교차 확인용(3배 이상 차이 시 경고)이다.

### 3.2 Bulk Modulus → 돌기 끝단 Modulus (E_tip)

- 기공률 보정 (Gibson–Ashby): E_tip = E_bulk / (1 − p)^n × f_wet. 개방기공 n = 2, 폐쇄기공 1~2. — Gibson & Ashby, *Cellular Solids* (1997)
- f_wet: 수화·온도에 따른 연화 비율 (기본 1.0). 나노압입 값이 있으면 E_tip 직접 입력.

### 3.3 속도·경화 보정 → 유효 경도 H_eff, 접촉역학용 E_dyn

CMP 슬라이딩에서 Pad 표면은 10⁶~10⁷ s⁻¹ 급 변형률 속도를 받고, 글레이징된 표면은 경화된다. 고분자는 변형률 속도가 오르면 E 와 H 가 함께 오르므로

- 자동: E_dyn = E_tip × f_rate, H_eff = (H/E) × E_dyn. f_rate 기본 5.
- 직접 입력: H_eff = 입력값, E_dyn = max(E_tip, H_eff/(H/E)). 경도 100 MPa 를 E 111 MPa 와 함께 쓰면 H/E ≈ 0.9 가 되어 비물리적이므로(일반 재료 H/E ≤ 0.2) E 를 끌어올린다.

E_dyn 은 GW 접촉계수와 Pad–입자 Hertz 에, H_eff 는 CEB 소성 돌기와 Pad 소성 반력에 쓴다.
IC1000 급(E_bulk 300 MPa)에서 f_rate 5 는 H_eff ≈ 330 MPa 로 과대할 수 있다. 문헌·측정의 50~150 MPa 범위를 맞추려면 f_rate 1~2 또는 직접 입력을 쓴다.

### 3.4 Pad 돌기 접촉 — Greenwood–Williamson + Chang–Etsion–Bogy

- 소성지수 ψ = (E*/H_eff)·√(σ/β). ψ < 0.6 탄성, > 1 소성. — Greenwood & Williamson, Proc. R. Soc. A 295, 300 (1966)
- 임계 간섭 ω_c = (π K H_eff / 2E*)² β, K = 0.454 + 0.41ν. — Chang, Etsion, Bogy, J. Tribol. 109, 257 (1987)
- 공칭압력 ↔ 분리 h 표를 만들어 실접촉면적비, 돌기 평균 접촉압력 p_a, 소성 하중 분담률 f_pl 을 구한다. 소성 접촉에서는 정의상 p_a = H_eff 이다.
- P_crit = f_pl = 0.5 가 되는 압력.

### 3.5 입자 수와 입자당 하중

- wt% → φ, n_v = φ/(πd³/6), 계면 활성 면밀도 n_a = n_v^(2/3) × 활성비
- F_share = p_a / n_a
- **하중 평형 (R02)**: Pad 반력 F_pad(δ_p) 와 Wafer Hertz 반력 F_waf(δ_w) 가 같고 δ_p + δ_w = 2R 인 δ_p 를 이분법으로 푼다.
  - Pad 소성(ψ>1 또는 f_pl ≥ 0.5): F_pad = H_eff · A_cap(δ_p), A_cap = π(2Rδ_p − δ_p²), δ_p ≥ R 이면 πR² 로 포화
  - Pad 탄성: F_pad = (4/3) E*_pp √R δ_p^1.5 (δ_p ≤ R)
  - F_waf = (4/3) E*_wp √R δ_w^1.5
- F_p = min(F_share, F_bal). F_bal 이 지배하면 Head 압력이 아니라 Pad 경도가 입자 하중을 정한다.
  — 입자 분담 개념: Luo & Dornfeld, IEEE Trans. Semicond. Manuf. 14, 112 (2001)

**하중 평형의 기하 닫힘에 대해.** 평형식만으로는 δ_p 가 정해지지 않고 "입자 위치에서 Pad 표면–Wafer 간극" 조건이 필요하다. 소성 돌기 접촉 내부는 Pad 가 Wafer 에 밀착(간극 0)하므로 δ_p + δ_w = 2R 을 쓴다. Wafer 가 Pad 보다 훨씬 단단해 δ_w ≪ R 이므로 δ_p ≈ 2R − δ_w > R 이 되어 투영면적이 πR² 로 포화하고, 결과적으로 F_bal ≈ H_eff·πR² 가 된다. 즉 "F ∝ R² → 경도 지배 영역의 접촉압력이 크기와 무관" 은 모델의 버그가 아니라 간극 0 가정의 귀결이다. 크기 의존성은 수화층 관통 기준(3.7절)에서 δ_h/R 비가 상수가 되어 **임계 응집체 지름** 으로 나타난다.

### 3.6 입자–Wafer 접촉 (벌크)

- Hertz: a = (3F_pR/4E*_wp)^(1/3), p_m = F_p/πa², δ_w = a²/R
- 항복 시작 1.1 Y_w (Y_w ≈ H_w/2.8), 완전 소성 p_m ≥ H_w — Johnson, Contact Mechanics (1985); Tabor (1951)
- 경도 지배 영역 p_m = (16 k E*²/9π³)^(1/3), k = F_bal/R². 벌크 항복에 필요한 Pad 경도 H_eff = 9π² (1.1Y_w)³ / (16E*²)

### 3.7 스크래치 판정

CMP 스크래치는 폭·깊이 수십 nm 의 소성 홈이다. K_IC 기반 파괴역학 임계하중(mN 급)은 이 스케일에 맞지 않아 쓰지 않는다.

**① 나노스크래치 — 수화층 관통.** 산화막·Cu 표면에는 슬러리 화학으로 연화된 수화층(두께 t_h, 경도 H_h)이 있다. 입자가 이 층을 관통하면 폭 수십 nm 의 홈이 남는다.
1. Hertz p_m ≥ 1.1·H_h/2.8 이면 수화층이 소성 변형.
2. 경도 정의 H_h = F/(πa_h²) 로 압흔 반경 a_h, 깊이 δ_h = R − √(R² − a_h²).
3. δ_h ≥ t_h 이면 나노스크래치. 홈 폭 = 2a_h.
4. 관통에 필요한 하중 F_need = H_h · π(2Rt_h − t_h²), Pad 국소 압력 F_need/πR², 홈 폭 2√(2Rt_h − t_h²) 을 함께 출력.
5. 임계 응집체 지름: F = k·R² 이면 δ_h/R = 1 − √(1 − k/πH_h) 가 상수 → d_c = 2t_h/(δ_h/R).

검산 (R = 50 nm, H_h = 1 GPa, t_h = 2 nm): a_h = 14 nm, 홈 폭 28 nm, F_need = 0.62 μN, F_need/πR² = 78 MPa.
H_eff = 11 MPa(정적) → F_p = 0.09 μN → 불가. H_eff = 100 MPa(글레이징) → F_p = 0.79 μN → 발생, 폭 31.6 nm.

**② 깊은 스크래치 — 벌크 잔류 압흔.** Hertz p_m ≥ 1.1Y_w 일 때 H_w = F/(πa²) 로 잔류 압흔 깊이를 구하고 δ_th 와 비교. 임계 응집체 지름도 같은 방식.

**상위 분위수와 LPC.** 입자 지름을 중앙값 d, 변동계수 CV 의 로그정규로 보고 d_99.9 = d·exp(3.09·σ_ln) 에서 하중과 ① 판정을 반복한다. LPC 는 개수 농도이므로 (LPC)^(2/3) 를 계면 면밀도로 보고 실접촉면적비 × 300 mm 웨이퍼 면적을 곱해 순간 접촉 수를 추정하며, d_L 을 임계 지름과 비교한다.

## 4. AFM / 거칠기 측정값 → GW 파라미터

| GW | 측정값 (ISO 25178-2) | 환산 |
|---|---|---|
| σ [μm] | Sq (또는 Rq) [nm] | σ = Sq / 1000 |
| β [μm] | Spc [1/mm] | β = 1000 / Spc |
| η [/mm²] | Spd [/mm²] | η = Spd |

- Ra, Rp, Rpk, Rz 는 GW 파라미터로 바로 바뀌지 않는다. Rq 만 있으면 σ 만 갱신.
- 선 프로파일의 스펙트럼 모멘트(McCool, Wear 107, 37, 1986)로도 환산 가능 (GUI 미구현).
- 스캔 크기 주의: Pad 돌기 간격은 수십~수백 μm 라 AFM 소영역 스캔은 돌기 위 미세 거칠기를 재기 쉽다. 돌기 수준 값은 200 μm 이상 영역에서 뽑는다.

## 6. 모델 한계 · R03 후보

- Pad 를 탄소성 연속체로 본다. 점탄성·윤활은 없고, 기공·속도 효과는 E_tip, f_rate 보정으로만 반영한다.
- 입자 하중 평형은 간극 0 가정이다. 돌기 접촉 가장자리나 탄성 접촉에서는 간극이 있어 F_bal 이 작아진다.
- 스크래치 판정은 정적 압입 기준이다. 접선 하중(마찰계수 μ)에 의한 후단 인장응력 증폭과 pile-up 은 R03 후보.
- 로그정규 CV, LPC 접촉 수는 추정치다. 실측 PSD 가 있으면 그 분위수를 d_99.9, d_L 에 직접 넣는다.
